Validación de Contraste y Ergonomía Visual

Evalúa la accesibilidad de tu paleta mediante el marco normativo legal vigente (WCAG 2.1) o con el algoritmo perceptual de última generación para diseño digital (APCA / WCAG 3).

Método WCAG 2.1 (Legal & Auditoría)
Estándar regulatorio obligatorio

Utiliza una fórmula matemática pura de luminancia relativa con ratios fijos (4.5:1 para texto normal, 3.0:1 para texto grande).

  • Obligatorio para: Auditorías de accesibilidad, cumplimiento legal (ADA, Section 508, EN 301 549) y certificaciones gubernamentales.
  • Limitación: No toma en cuenta el modo oscuro ni la frecuencia espacial de la fuente.
Método APCA (WCAG 3 - Percepción Humana)
Algoritmo moderno para diseñadores UI

Diseñado para pantallas autoiluminadas. Modela la adaptación visual, la polaridad claro/oscuro y prescribe tamaños mínimos de fuente exactos.

  • Recomendado para: Decisiones de diseño UI/UX reales, ergonomía visual en modo oscuro y selección de tipografía (px y peso).
  • Ventaja: Evita falsos positivos y falsos rechazos en interfaces digitales modernas.
